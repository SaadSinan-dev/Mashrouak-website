MASHROUAK.NET — دليل التسليم الحالي — 10 نوفمبر 2026

ابدأ بفتح docs/FINAL_DEPLOYMENT_HANDOFF.md.
نتائج الاختبارات وحالة الجاهزية الفعلية: docs/PRODUCTION_READINESS_REPORT.md.

البنية المعتمدة:
Cloudflare Pages: mashrouak-net للموقع و mashrouak-admin للوحة الإدارة.
Render Free: خدمة Node.js/Hono الحالية فقط.
Neon Free PostgreSQL: قاعدة البيانات الحالية.
Cloudinary: التكامل الحالي للصور.
لا تنشئ موارد مدفوعة أو قاعدة Render أو قرصاً أو خدمة بديلة، ولا تعدّل DNS.
المقترحات القديمة المدفوعة ملغاة.

1. غيّر كلمة مرور دور Neon المكشوفة. احتفظ بالروابط الجديدة في إعدادات سرية فقط.
   DATABASE_URL للاتصال المجمّع و DIRECT_DATABASE_URL للاتصال المباشر؛ كلاهما مدعوم فعلياً.
   لا ترسل أي رابط أو كلمة مرور في المحادثة. لا تستخدم كلمة المرور القديمة.

2. احفظ نسخة من PostgreSQL المحلية قبل تغيير إعداداتها، واحتفظ بملفي المصدر:
   backend/.local/migration/source-local.json
   backend/.local/migration/source-local.json.sqlite
   لا تستبدلهما بالمصدر البعيد الفارغ، ولا تستورد فوق بيانات مختلفة.
   يتضمن دليل التسليم أوامر فحص الاتصال ومقارنة البيانات دون استيراد.
   تنفيذ ترحيل مخطط Neon أو الاستيراد أو تصحيح المحتوى البعيد يتطلب موافقتك الصريحة.

3. افتح خدمة Render الحالية وتحقق من Free و main و Node 24.19.0.
   Root: repository root
   Build: npm ci --include=dev && npm run build -w @mashrouak/backend
   Start: npm run start -w @mashrouak/backend
   Health: /healthz
   لا تستخدم pre-deploy job في الخطة المجانية.
   يحتوي دليل التسليم على جدول كل المتغيرات ومسار Environment Group.

4. اضبط Pages بشكل مستقل:
   الموقع: npm run build — output dist
   الإدارة: npm run build -w @mashrouak/admin — output admin-dashboard/dist
   كلاهما من جذر المستودع وعلى main.
   API_PROXY_URL: أصل HTTPS الفعلي لخدمة Render، دون /api.
   PAGES_PROXY_SECRET: القيمة السرية نفسها في Render ومشروعي Pages.
   VITE_API_URL: فارغ للحفاظ على /api من الأصل نفسه.
   VITE_PUBLIC_URL في الإدارة: أصل الموقع العام الفعلي.
   لا تضع أي أسرار في متغير يبدأ بـ VITE_.

5. راجع التغييرات كاملة قبل الموافقة على Git Push؛ قد يطلق نشر التطبيقات الثلاثة تلقائياً.
   بعد النشر، نفّذ فحص /healthz وتسجيل الدخول وثلاث عمليات نشر متتالية لنفس العنوان.
   تحقق من API والنافذة المفتوحة ونافذة خاصة والتحديث، ومن بقاء المسودة غير المنشورة خاصة.
   اختبر خدماتنا بالعربية والإنجليزية والصور والجوال وإيقاظ Render بعد الخمول.

الحالة الفعلية: أصلح عطل startup search_path محلياً واختبرت الشيفرة والبناء والتكامل والمتصفح.
لم أستخدم بيانات Neon القديمة ولم أنفذ نشر الإصلاح أو ترحيل Neon أو الاستيراد البعيد.
الفحوصات المستضافة ما زالت معلّقة على خطوات حساباتك وموافقتك على الكتابات المحددة.
التفاصيل والأوامر القابلة للنسخ موجودة في ملفي التسليم والجاهزية أعلاه.
